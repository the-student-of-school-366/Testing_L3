Нагрузочное тестирование REST API

Закрытая нагрузка на локальный сервис этого репозитория. Виртуальные пользователи логинятся, читают профиль, создают пост, читают его и обновляют заголовок. Данные каждой итерации берутся из CSV, перед каждым запросом — постоянная пауза.

Сформирован 2026-11-10 19:21:17 MSK · цель: http://127.0.0.1:57110

Поднят in-process сервер с тем же router, что и cmd/server, включая middleware логирования. Журнал сервера: loadtest/results/server.log.

Параметризация: loadtest/data/posts.csv, 15 строк. В запросах используются username, password, title, body, user_id, patched_title. Пауза: 200 мс перед каждым запросом (constant think time).

Сценарий и проверки

  1. POST /api/v1/auth/login — HTTP 200, непустой access_token, username совпал с CSV.
  2. GET /api/v1/auth/me — HTTP 200, Bearer-токен, username и email на месте.
  3. POST /api/v1/posts — HTTP 201, id не пустой, title и user_id совпали с CSV.
  4. GET /api/v1/posts/{id} — HTTP 200, тот же id и исходный title.
  5. PATCH /api/v1/posts/{id} — HTTP 200, title равен patched_title.

Вывод

В установившемся окне 15 с при полной конкуренции throughput вырос с 50.0 до 248.9 RPS — в 4.98 раза при росте числа пользователей с 10 до 50 (в 5.0 раза).

Среднее время ответа изменилось с 0.496 до 0.231 мс, медиана — с 0.505 до 0.000 мс, p95 — с 1.577 до 0.759 мс. Медиана 0 мс означает, что не меньше половины ответов короче шага таймера и записаны как нулевые. Среднее и p95 остаются в субмиллисекундном диапазоне: это шум измерения на localhost, а не ускорение сервиса.

Ошибок нет ни на одном уровне нагрузки: error rate в установившемся окне равен 0%.

Момент деградации не наблюдался. Throughput остаётся близким к потолку think time (200 мс перед каждым запросом, около 5 RPS на пользователя). Потолок по уровням: 50 RPS при 10 пользователях; 125 RPS при 25 пользователях; 250 RPS при 50 пользователях. p95 остаётся небольшим, доля ошибок не растёт.

Стабильным можно считать весь исследованный диапазон: 10, 25, 50 виртуальных пользователей. До отказа сервис не доводился.
